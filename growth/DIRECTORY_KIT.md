# Directory submission kit — owner-gated

Referring domains are ~0, and that is the single reason well-optimised pages sit
at position 84. Directories are the only backlink source that needs no
relationship and no outreach — but every one of them needs an account, an email
confirmation or a human check, so they are the owner's to do. This file exists
so that takes twenty minutes rather than an evening: the copy is written, the
categories are chosen, and the order is by return.

**Rules that do not bend.** No paid link packages, no link exchanges, no
directories that exist only to sell links, no fake reviews — those are the
schemes that get a domain penalised, and the site would lose more than it gains.
If a directory asks for money to be listed, skip it and note it here.

## The copy — paste these, do not re-write per site

Consistency across listings is itself a ranking signal: the same name, the same
description and the same URL everywhere is what lets a search engine treat them
as one entity.

**Name:** QRix

**URL:** https://qrixtools.com

**Tagline (≤60 chars):**
`180+ free file and QR tools that run in your browser`

**One line (≤160 chars):**
`QRix is a free toolbox for QR codes, PDFs, images, video and AI — most tools run entirely in your browser, so files never leave your device.`

**Short (≤300 chars):**
```
QRix is a free online toolbox: QR code generation and scanning, PDF conversion
and compression, image editing and conversion, video tools, and AI utilities —
180+ in total. Most run entirely in the browser, so your files are never
uploaded. No account is needed to use them.
```

**Long (≤1000 chars):**
```
QRix is a free toolbox for the small file jobs that usually mean either
installing something or uploading a document to a stranger's server.

It covers QR codes (30+ types, including dynamic links with scan analytics and
a bulk CSV generator), PDF tools (merge, split, compress, OCR, convert),
image tools (background removal, format conversion, resizing to exact targets,
passport photo cropping), video tools, barcodes in 13 symbologies, and a set of
AI utilities.

The part that matters: almost everything runs in your browser. The image and
PDF work happens on your device, so the file is never uploaded — which is why
the tools work on a signature, a contract or a passport photo without a privacy
question. The pages say plainly which few tools do send a file to a server.

Free to use, no account required for the tools themselves, and no watermark on
what you download.
```

**Categories to pick, in order of fit:** Utilities · Productivity · Design tools ·
File conversion · QR codes · Developer tools

**Tags:** qr code generator, pdf tools, image converter, background remover,
barcode generator, privacy, browser-based, free tools

**Pricing to declare:** Free (a paid Pro plan exists for the API and higher
limits; the tools are free)

**Screenshots to have ready:** homepage, /image-tools, /qr-tools/url with a

## Two things worth more than the whole list

1. **A page other people want to cite.** /qr-code-statistics was built for this —
   26 figures, each with its source and its caveat, plus an embeddable card per
   figure that links back. One journalist or blogger using a card is worth more
   than five directory listings. The next asset of that kind is the "we tested 20
   free QR generators" methodology page, already at the top of the backlog.
2. **The Telegram channel and bot**, which are live. A tool people use weekly
   produces direct traffic that owes nothing to a ranking.

## Recording results

Add each live listing to `growth/SEO_STRATEGY.md`'s Baseline block as a
referring domain, with the date. The number to watch is not the count of
submissions — it is referring domains that actually resolve, which is what moves
position off page 8.
