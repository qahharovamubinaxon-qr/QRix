## 3. Habr мақоласи — энг катта таъсир

Нега биринчи ўринда эмас, лекин энг қимматли: Habr домени кучли, ва **аудиторияси
айнан сеники** — Яндекс аналитикаси трафикнинг асосий қисми МДҲ'дан эканини кўрсатяпти
(`ok ru downloader` → 23% CTR, `размер фото 413 на 531` → 40% CTR).

### 3.1 Мавзу — текширилган, ҳақиқий

`lib/tiff-decode.ts` (129 қатор, `components/image/ImageConvertClient.tsx` дан чақирилади,
яъни **браузерда** ишлайди):

- LZW, PackBits, Deflate/ZIP, **CCITT fax (G3/G4)** сиқишларини ечади
- кўп саҳифали сканларда **саҳифа танлаш** бор (`decodeTiffPage(buf, page)`)
- ечиб бўлмайдиган ҳолат учун алоҳида `TiffUnsupportedError` — жим қолмайди

Бу ҳақиқий муҳандислик мавзуси. TIFF — эски, мураккаб формат; уни серверсиз,
браузерда ечиш ҳақида рус тилида яхши мақола кам.

### 3.2 Сарлавҳа вариантлари

```
Как мы декодируем TIFF прямо в браузере: LZW, PackBits и факсовый CCITT
```
```
TIFF без сервера: разбираем многостраничные сканы на клиенте
```

### 3.3 Мақола режаси

1. **Муаммо.** Сканерлар ва факслар ҳали ҳам TIFF беради. Онлайн конвертерлар уни
   серверга юклашни талаб қилади — ҳужжат эса кўпинча шахсий (паспорт, шартнома).
2. **Нега браузерда қийин.** `<img>` TIFF'ни кўрсатмайди. Canvas ҳам. Декодерни ўзинг
   ёзишинг керак.
3. **IFD тузилиши.** Тегларни ўқиш, қайси сиқиш ишлатилганини аниқлаш.
4. **Сиқиш усуллари бўйича.** LZW (энг кенг тарқалган), PackBits (оддий RLE),
   Deflate, ва энг қизиғи — **CCITT fax G3/G4**, факс аппаратларидан қолган мерос.
5. **Кўп саҳифали сканлар.** Нега саҳифа танлаш керак ва қандай қилинган.
6. **Нимани қўллаб-қувватламаймиз ва нега жим қолмаймиз.** `TiffUnsupportedError` —
   фойдаланувчига «бўлмади» дейиш, нотўғри расм кўрсатишдан яхши.
7. **Хулоса.** Нима ўргандик, қайси ҳолатда сервер барибир керак.

### 3.4 Қоидалар — буларсиз мақола ўчирилади

- ❌ Реклама оҳанги йўқ. Бу **техник мақола**, маҳсулот эълони эмас.
- ✅ Ҳаволани **бир марта**, матн ичида, табиий жойда бер.
- ✅ Код парчалари бўлсин — Habr ўқувчиси кодсиз мақолани жиддий қабул қилмайди.
- ✅ Шарҳларга жавоб бер. Habr'да муаллиф жавоб бермаса, мақола ўлади.
- ❌ «Мы сделали лучший конвертер» — ҳеч қачон.
