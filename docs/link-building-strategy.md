# QRix — link-building / outreach strategy

The 3 Sep benchmark showed the on-page work is done (0 P0 / 0 P1) but the domain
has **no off-site authority**, which is why it does not rank on competitive Google
terms. This is the highest-leverage remaining work. It is **manual** — no automated
submission, no spam. The mission rules and QRix's own rules forbid fabricated
backlinks; every link below must be earned by a real submission the owner approves.

Status legend: `todo` / `submitted` / `live` / `rejected`.

## Tier 3 — Russian / CIS sphere (matches the real audience)

QRix's traffic and downloader strength are CIS-facing. Directories and communities
there are lower-competition and better-matched than the English-first ones:

| Target | Relevance | Angle | Status |
|---|---|---|---|
| Telegram tool/tech channels | high | already have an autoposter; earn mentions, don't spam | todo |
| VC.ru / Habr (if a genuine technical post) | high | write-up, not an ad | todo |
| Regional "free tools" directories | medium | VK/OK downloader breadth | todo |

## Rules

1. **One honest differentiator per listing.** Never "the best" — say the true thing
   (no upload / no signup / no expiry / free forever) and let it stand.
2. **No reciprocal-link schemes, no paid link networks, no PBNs.** These are the
   fabricated-backlink pattern the rules prohibit and Google penalises.
3. **Match the audience.** A CIS-facing product earns more from Habr + Telegram than
   from a US directory. Weight effort toward Tier 3.
4. **Track every submission** in the status column so nothing is double-submitted and
   the owner can see what is pending.

## Why this over more content

The competitor gap analysis and benchmark agree: QRix loses head terms on authority,
not on page quality. Ten good directory + community links move the needle more than
ten more tool pages. Do this before writing new content.
